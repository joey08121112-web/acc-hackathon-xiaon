## 一、项目应该怎样讲

**项目名称：学伴小N。**

**一句话介绍：一款从七年级数学切入的 AI 学习伙伴，先听学生说出困难，再陪他分步尝试，用作答记录和同类新题呈现具体的学习变化。**

适合视频封面的主张：

> **学伴小N，陪你把卡住的那一步，想明白。**

可以围绕三个问题讲完整个产品：

1. **卡在哪里？** 学生先表达，小N提出一个可以被确认、纠正的卡点猜想。
2. **这一小步怎么走？** 学生先尝试，需要时请求逐级帮助，也能暂停。
3. **换一道题，还能自己做吗？** 学生选择未见同类题核对，系统区分提示后完成、原题改对和本次新题独立完成。

录制时，以一位学生的一段学习经历串起这些问题。五维观察、计划、记忆和家长周小结作为这段经历的延伸。

## 二、我们希望解决什么问题

项目关注这样一种学习场景：学生知道自己“不会”，却未必能说清具体卡点；看懂一次讲解之后，也需要再试一次，才知道自己能走到哪里。

小N围绕这段过程提供支持：让学生有机会表达和纠正，让提示贴近当前步骤，让结果有作答依据，让下一步安排保留选择权。

这是产品所针对的场景与设计目标。本项目尚无真实学生研究或长期提分数据，宣传中不应将这些目标写成已经证明的效果。

**当前对象与范围：** 从七年级数学的有限题库和具体子技能开始；新增的完整教学闭环聚焦“去括号负号处理”。更广泛的学段、学科与任意题辅导属于后续方向。

## 三、当前产品的六个讲解重点

### 1. 先听学生表达，再核实卡点

首页以小N为统一交流入口，学生可以聊天、进入学习或休息。在“去括号负号”学习片段中，学生先写出自己的困惑，小N再提出卡点猜想，学生可以确认，也可以改成更准确的描述。

**可用话术：**“小N会先听你说，再让你确认：它理解的，究竟是不是你卡住的那一步。”

### 2. 一次试一小步，帮助过程会留下记录

学生先留下自己的尝试，再根据需要请求提示。新增闭环提供逐级帮助，三级后可以换一种表示方式继续理解。学生可以继续当前题、回顾、暂停或结束。

系统保存原始作答、修改和已显示的帮助。提示后做对有它自己的记录，不会被归为首次独立完成。

**可用话术：**“每一次尝试、每一次求助，都能成为回看学习过程的线索。”

### 3. 用未见同类题核对本次表现

学生可以选择一道未见同类题再试。系统核对是否已经接触过题目，并记录这次是否使用帮助、是否修改。

**可用话术：**“做完之后，还可以换一道同类新题，看看这一次自己能走到哪一步。”

结论限于具体题目和子技能。当前换数变式不能证明跨情境迁移；同日一次正确也不能证明长期掌握。

### 4. 从五个角度观察数学学习

专业模式包括理解、逻辑、计算、建模、空间想象五个模块，通过有限任务和追问收集观察依据，形成分模块报告。

| 角度 | 视频中可以怎样解释 | 当前示例范围 |
| --- | --- | --- |
| 理解 | 能不能读清条件和运算顺序 | 数学语句与条件提取 |
| 逻辑 | 能不能用例子检验一句话 | 反例与条件、结论 |
| 计算 | 能不能正确处理式子 | 去括号负号、合并同类项 |
| 建模 | 能不能把生活关系写成式子 | 一次费用与随数量变化的费用 |
| 空间想象 | 能不能判断位置变化 | 二维旋转与位置关系 |

**可用话术：**“小N从五个角度记录这次任务中观察到了什么，并展示相应依据。”

这里属于有限任务下的学习观察，尚未完成标准化测评效度验证。报告不提供总分和排名。

### 5. 把观察接到计划与复习

系统已有报告、月目标、周计划和到期复习链路。计划以草案形式呈现，学生可以接受、减量、改期或暂不开始；新增负号闭环也能进入针对该子技能的复习建议。

**可用话术：**“看见这次做到哪里，再一起决定下一步。计划的分量和开始时间，都留给学生选择。”

到期复习在打开应用时查询；系统通知推送不是当前已完成能力。跨天、跨月演示若使用测试时钟，应在画面注明“时间模拟”。

### 6. 给家长看具体变化，也给学生保留空间

家长页已接入结构化学习记录，包含当前目标、计划、休息状态、知识点观察、下一次复习和每周小结。小结能区分提示后完成、新题独立完成等情况，并提供沟通建议。

当前家长小结不展示聊天、倾诉、可选记忆和学生作答原文。学生的可选偏好记忆可以关闭、更正、停用或删除；必要学习记录另有用途。

**可用话术：**“家长可以看到孩子在小N里尝试了什么、哪些地方出现变化，也能得到更具体的交流建议。”

这是界面的内容边界。当前账号隔离、真实监护核验和整套隐私安全验收仍有待完善，不宜宣传为已经完成的安全体系。

## 四、最值得录的一段演示

**建议用一个负号错误串起视频主线。下面是预设的合成学生演示，不是真实学生案例或教学效果数据。实际题目以演示环境当时选出的未见题为准。**

| 步骤 | 画面与操作 | 讲解重点 |
| --- | --- | --- |
| 进入 | 首页点击“一起看看去括号的负号” | 展示一个清楚的学习入口 |
| 表达 | 输入“我去括号时，第二项总忘记变号” | 从学生的具体困惑开始 |
| 核实 | 确认卡点，或演示“我想纠正” | 学生可以纠正 AI 的理解 |
| 首次尝试 | 若题面为 `3x − (2x − 5)`，输入 `x-5` | 保留真实的这次尝试 |
| 请求帮助 | 点击“给这一步一点提示”，再改为 `x+5` | 展示“提示后改对”的记录 |
| 新题核对 | 选择“用一道未见同类题核对” | 由学生选择是否核对 |
| 再次尝试 | 若新题为 `7a − (3a − 2)`，首次提交 `4a+2`，期间不再请求帮助 | 据实显示本次新题表现 |
| 回顾 | 展示回顾卡，可编辑或跳过总结、信心 | 感受由学生表达，结论受记录约束 |
| 下一步 | 展示复习建议和学生确认按钮 | 把一次练习接到后续学习 |

若环境里尚无合并同类项先修记录，先按入口提示完成小题，再进入负号片段。已有记录可能影响选题；不要将固定答案输入到不同题目中。

若跳过新题、求助后才做对，或结果待核查，就保留对应画面和措辞。这些分支也能展示产品怎样对待不确定的学习结果。

## 五、约三至四分钟口播稿

以下可直接朗读，时长随语速、操作停顿而变化。

> 有时候，数学学习最难的，是把“我不会”说得更具体一点。
>
> 是题目没读懂，还是知道公式，却不知道这一步怎么用？
>
> 我们做了学伴小N，一款从七年级数学切入的 AI 学习伙伴。我们希望它能陪学生说出困难、尝试一步，再看见自己具体做到了哪里。
>
> 比如，一个学生说：“我去括号的时候，第二项总忘记变号。”
>
> 小N会先提出一个卡点猜想。学生可以说“是这个卡点”，也可以纠正它。学习从双方确认的那一步开始。
>
> 接下来，学生先试一道题。如果暂时做不出来，可以请求一点提示，也可以继续尝试、换一种表示，或者先休息。系统会留下原始作答和帮助记录。
>
> 这里有一个我们很看重的细节：提示后做对、同一道题改对，以及第一次独立做对，会被分别记录。每一种结果，都有它自己的意义。
>
> 学生还可以主动选择一道没见过的同类题，再试一次。系统根据这次实际发生的作答，说明他做到了哪里。一次同类新题做对，结论就只写到这一次，不会直接推成长期掌握。
>
> 做完之后，小N可以整理一张回顾卡。学生能补充自己的收获，也可以跳过总结和信心自评。什么时候继续、要不要看复习建议，都由学生选择。
>
> 在更完整的专业模式里，小N还会从理解、逻辑、计算、建模和空间想象五个角度，记录有限任务中的表现，给出带依据的报告，再接到月目标、周计划和到期复习。
>
> 家长也有自己的学习概览和每周小结，可以看到孩子在小N里做过的尝试、出现的变化，以及可以怎样交流。这个小结不展示孩子的聊天和倾诉原文。
>
> 在技术上，我们把交流、作答分析、报告规划和受控出题分工处理。程序负责流程、记录和可确定的数学核对，模型负责受约束的分析与表达。
>
> 目前，完整的新教学闭环聚焦去括号负号，自动出题限定在去括号和合并同类项。我们正在打磨这个数学学习原型，真实学生体验和长期学习效果还需要继续验证。
>
> 学伴小N，陪你把卡住的那一步，想明白。

## 八、对评委解释技术时的简短版本

> 前端是手机网页，后端用 Node 和 SQLite 保存学习过程。Tutor 负责交流，Assessor 分析作答，PlannerReporter 整理报告和计划，Generator 提出限定范围内的题目候选。程序控制学习阶段、学生确认和记录；可确定的计算由程序核对，需要语义理解的内容由模型辅助分析。受控出题还要经过白名单模板和独立验算，才能发布。

这套分工的价值，是让结论能回到具体尝试、帮助记录和评分依据。它降低了自由生成直接进入学习结论的风险，但仍需要持续验证模型分析、题库覆盖和真实体验。

### 录制前快速准备

1. 使用包含当前教学闭环的版本。旧离线体验包缺少后续功能，不适合展示本报告全部内容。
2. 使用独立演示数据与合成身份。不要重置队友或线上共享库来准备镜头。
3. 先手动走通一次“卡点→作答→帮助→新题→回顾”，确认题面与脚本一致；若选题变化，按实际题面改稿。
4. 展示有内容的五维报告、计划或家长小结时，预先准备并明确标注合成演示记录。空记录也可如实展示，不补造真人历史。
5. 若录语音，先试听并核对麦克风可用性。本次未验证当前服务的语音配置。
6. 本地启动按应用 README 执行 `npm run dev:learning`，默认访问 `http://127.0.0.1:5194/`。端口冲突时按 README 换端口。当前公网链接、部署版本和可用性本次未复核，录制前另查。
