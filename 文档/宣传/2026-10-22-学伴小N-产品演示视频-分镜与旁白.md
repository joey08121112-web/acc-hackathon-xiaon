# 学伴小N 产品演示视频 · 分镜与旁白

编制日期：2026年10月22日。5分钟版视频文件：同目录 `2026-10-22-学伴小N-产品演示.mp4`（1920×1080，约5分17秒，旁白为豆包TTS小N音色，带硬字幕）。

录制方式：本机 `npm run dev:learning` 的独立演示库（`.local/promo-demo.sqlite`，合成学生身份），真实智谱模型回复；Playwright 自动点击并逐帧录屏，点击处有绿色波纹。模型等待时间已剪短；专业模式第2–5站以约5倍速快进；部分片段做了1.2–1.6倍加速。没有使用测试时钟，也未触碰线上或日常数据库。
