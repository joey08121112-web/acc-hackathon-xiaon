# 2026-10-24 语音链路检查与时延实测

## 当前结论

用户反馈设备为手机 Safari。本次服务器检查基于已部署的 `60cb46e`。

- 生产 `/api/health`：`voice.tts=true`、`voice.asr=false`。
- 服务器已配置语音 Key，ASR 没有独立 Key，沿用 TTS Key；目标资源为 `volc.bigasr.auc_turbo`。
- 从正在运行的生产容器直接请求供应商，收到 HTTP 403、`X-Api-Status-Code=45000030`、`[resource_id=volc.bigasr.auc_turbo] requested resource not granted`（约 156ms）。这证明当前 Key 没有这个识别资源的使用权限；不能单凭此结果区分账号未开通与 Key 未获授权。
- 通过生产容器的 HTTP 路由创建临时 API 会话并提交合成静音 WAV，`/api/voice/asr` 收到请求，约 120ms 返回 HTTP 500，业务错误 `provider_auth`。没有写入学习记录，也没有使用用户录音。
- 前端在 health 的 ASR 为 false 时选择浏览器 `SpeechRecognition`。因此按当前配置，Safari 正常的语音输入路径不会上传录音到本应用后端；只有浏览器识别出文字，才调用 `/api/learning/chat`。
- 历史日志没有语音请求分阶段追踪，因此无法追溯用户当时那次 Safari 请求是否成功。当前证据不支持“后端已有识别文字、只是前端没收到”。

供应商接口与资源 ID 参考：[火山官方录音文件识别极速版文档](https://docs.volcengine.com/docs/DoubaoVoice/LargemodelrecordingfileLiterecognitionAPI?lang=en)。资源权限结论来自本次生产容器的实际响应。

## 真实模型速度

在生产容器中使用同样的 GLM 模型、配置和 HedgedProvider，以及真实 TTS，建立独立临时 SQLite 库，调用首页 `d.chat(flow=home)`。三轮均为合成闲聊材料，模型 run 均 completed；未修改生产学习库。以下是应用协调器完整返回文字、以及整段回复音频合成完成的耗时。

| 轮次 | 对话文字返回 | TTS 音频生成 | 两段合计 |
| --- | ---: | ---: | ---: |
| 1 | 1.528 秒 | 1.111 秒 | 2.639 秒 |
| 2 | 2.169 秒 | 1.048 秒 | 3.217 秒 |
| 3 | 5.344 秒 | 1.462 秒 | 6.806 秒 |

三轮合计中位数 3.217 秒，范围 2.639–6.806 秒。样本仅三轮，不能视为稳定 SLA 或 P95。

这些数值**不包含**：人说话时间、端点静音等待（服务器录音路径当前为约 1.4 秒）、语音识别、手机与服务器网络传输、前端附加 reload 请求、音频开始播放的等待时间。ASR 未授权，所以没有测出真实手机端完整语音链路时延。另测固定合成句 TTS 约 0.898 秒。

测试过程中曾先用未注入真实 ModelProvider 的临时 fixture 跑过规则回复；那次毫秒级结果不属于真实模型证据，已排除，不用于本表。

当前实现依次等待整段录音识别、整条模型回复、完整 TTS 音频，不是流式语音。可实现自动轮次的连续对话，但目前不能宣称达到自然实时交流。若要降低停顿，需要先修通服务端识别，再分别评估流式 ASR、模型增量输出和分句/流式 TTS；本次没有擅自更换供应商或模型。

用户登录后，读取了当前账号 default 项目的豆包语音“开通管理”：流式语音识别2.0、录音文件识别2.0均显示“未开通”。另用服务器当前 Key 对新版资源 `volc.seedasr.auc` 做一次合成静音请求，同样收到 HTTP 403 / `45000030` / requested resource not granted，约158ms。没有切换生产资源配置。

控制台的说明写明：体验中心免费试用与正式服务开通不同；正式开通后若有剩余免费额度会迁入项目，额度耗尽会自动进入正式计费。本次只读取状态，没有开通服务、购买套餐、扩大 Key 权限或复制 Key。尚不能证明该登录账号就是服务器 Key 的归属账号；当前两项证据分别成立。

## 本次代码变更

- 首页去除按住/松开手势，改为点击开始整段语音会话，再次点击结束。
- 用户开启后，识别出一轮话 → 发送 → 等模型回复 → 等回复音频播放结束 → 重新听下一轮。
- 点击结束、切到打字、离开首页、休息、切后台时关闭麦克风；识别结果晚到不再发送；结束时已在进行的模型回复可保留文字，但不再自动朗读或重启麦克风。
- 麦克风授权晚到时释放音轨，不启动已被取消的录音；取消识别时中断上传；浏览器识别启动无响应及整轮过久时显示错误并退出，避免无限“在听”。
- 真实延迟下，等待提示音先结束也不会提前开始收音；语音轮次会等回复音频准备并播放后才续听。语音发起的轮次仅显示等待文字，不触发延迟固定提示录音，防止用户结束后仍听到“让我想想”。
- 后端 ASR 增加请求编号响应头、Server-Timing，以及 received/completed/failed/cancelled 元数据日志，不记录录音、识别原文、Key。
