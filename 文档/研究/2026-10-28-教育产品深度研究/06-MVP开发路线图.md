# 学伴小N：MVP开发路线图

研究建议v1.0｜2026-10-28｜本文件是供评审的路线，不表示已批准开发/部署或招募儿童。

## 1. MVP只验证一个问题

**在一个孩子愿意完成的建造任务中，小N的情境帮助能否支持孩子提出预测、做可比较的试验，并在之后的新任务里更独立？**

候选用户：10–12岁、主要五至六年级，具备任务所需基础阅读和整数理解；不是按年龄自动假设都会。候选体验：一个2D温室水路工坊，能搭、试、改、命名、保存，可聊天求助。第一学习目标是“比较时只改变一个因素并用结果解释”，不是五维总提升。

必须同时验证三个条件：孩子想参与、确有独立学习信号、团队能持续提供正确安全的内容。只满足好玩可定位为创作娱乐；只满足学习但孩子拒绝用，应重做体验；两者成立而AI无增益，可以先做规则提示产品。

## 2. P0/P1/P2优先级

| 优先级 | 功能/任务 | 为什么 | 验收条件 |
|---|---|---|---|
| P0 | 明确目标年龄/任务边界和儿童测试方案 | 防止现有七年级原型与新小学探索混为一谈 | 招募条件、排除项、任务目标、同意材料和停止条件经负责人确认 |
| P0 | 一个2D任务：温室水路 | 最小的完整体验 | 至少两种可行路线；预算/流量/撤销/存档正确；无AI也能玩完 |
| P0 | 可信任务状态和有限动作 | AI必须知道真实可做什么 | 不接受任意新物件/规律；状态过期建议被拒绝；目标由代码判定 |
| P0 | 固定分级提示＋AI情境帮助开关 | 能比较AI的额外价值 | 两条路径内容目标相当，帮助记录一致，AI不可改规则 |
| P0 | 开放问题简短回应与退出/安全路由 | 综合模式的基本价值 | 事实、拒绝、错误理解/风险回归集；退出后不再追问或播放 |
| P0 | 预测、试验、帮助、作品版本与解释记录 | 区分通关/理解/独立学习 | 记录可追溯；帮助后完成不冒充独立；不展示能力总分 |
| P0 | 保存/恢复/暂停与失败降级 | 不因技术挫败掩盖产品价值 | 弱网/刷新/重启不丢已确认作品；重复请求不重复扣币 |
| P0 | 主体隔离、监护/儿童同意、最小化与删除 | 儿童试点前提 | 不同主体不能互读/互删/互导出；撤回/派生清理通过；不能只看源码 |
| P0 | 内容和危险活动白名单、反馈/人工处理入口 | 问答和儿童探索会遇到真实风险 | 明显严重安全失败先修复，责任人/处理流程明确 |
| P0 | 一个即时未见任务＋一个延迟核对任务 | 不把使用时长当效果 | 未见/已见、间隔、帮助和缺失清楚记录；任务难度经预试 |
| P1 | 第二规则域（优先L2机器人或N2铺砖） | 检验内容扩展与迁移范围 | 每个域有目标、解见证、帮助、异题和专家审核 |
| P1 | 自愿兴趣记忆与跨模式任务邀请 | 有需求后再做连续个性化 | 来源/确认/期限/删除；兴趣邀请拒绝后停止 |
| P1 | 更完善家长作品概况/跨设备账户 | 真实连续使用需求 | 真实监护绑定、访问范围清楚、恢复和审计通过 |
| P1 | 语音按住说、真机优化、轻量装饰库 | 减少输入负担，提高归属感 | 真实儿童口音/设备可修正、文字替代、无强制麦克风 |
| P1 | B轻体素专项样机 | 仅当空间目标/儿童证据支持 | 同内容比较，空间收益足以承担操作/成本 |
| P2 | 多世界、更多模板和受控在线变式 | 内容生产能力证明后扩展 | 可解性与教学审核链稳定，维护成本可承受 |
| P2 | 复杂3D、多人合作、公开作品社区 | 要求额外内容/安全运营 | 单独商业与安全论证；无明确需求则长期不做 |

P2是远期候选，不是承诺一定实现。五维标准化测评、虚拟亲密关系、任意联网探索和完全自由实时生成世界不进入本路线。

## 3. 应暂缓的功能

完整3D沙盒、无限地形、生存采集/经济系统、多人同步、UGC公开评论/私信、全科课程、自动长期画像、五维雷达/常模、深度知识追踪训练、任意题目/任务实时生成、多Agent儿童导师团队、摄像头情绪识别、连续监听、收费虚拟情感角色、排行榜/连胜惩罚、自研硬件和复杂教师后台。

暂缓不意味着理论上没用，而是无法在首个实验中证明必要性。家长安全控制、主体隔离、必要内容审核和基本可达性不属于可删减项。身份和监护功能应按试点实际风险设计，并履行适用义务，不让一次“我已成年”点击承担所有责任。

## 4. 分阶段计划与决策闸门

以下是排期初案：一个主要开发者、至少一名能审核内容和观察研究的协作者。开发约4–8人周，验证/同意/运营工作另算，整体可能8–10周或更长。AI辅助编程不减少内容审核、真机和儿童研究的必要工作。若资源不足，减少规则域和美术，不同时取消验证和安全。

| 阶段 | 建议时间 | 产物 | 放行/停止条件 |
|---|---|---|---|
| G0 问题与概念验证 | 第1–2周 | 任务纸面/可点击样机、任务规则、6–8位目标儿童的受控观察方案、4–6位监护访谈计划 | 孩子理解目标、有主动操作意愿；若只想聊天或嫌任务无聊，先改任务，不扩功能 |
| G1 无AI游戏切片 | 第2–4周 | 确定性规则、两个见证解、操作反馈、撤销/保存/固定提示 | 完成路径无软锁；作品可恢复；任务能不靠成人代操作开展 |
| G2 AI与证据/安全集成 | 第4–6周 | 情境帮助、引用/动作校验、事件与报告、主体/同意/删除、合成评测 | 技术/安全门槛通过，固定提示与AI可切换；严重问题修好再儿童远程试点 |
| G3 两周可行性试点 | 第6–9周 | 12–20人，记录前测/体验/延迟、帮助与退出；含7±2天核对 | 兴趣、独立行为与运行成本有可解释信号；只作可行性，不能宣称效果已证明 |
| G4 投资决策 | 试点后 | 研究复盘、错误案例、成本账、下一轮预注册实验 | 学习信号与自愿参与并存才扩大；是否AI/3D由数据决定 |

阶段可重叠，但儿童数据收集依赖同意/安全门槛，不能先收集再补授权。本报告仅提供研究方案，不已执行招募/联系任何人。

## 5. MVP内容包的最小范围

一张6×4网格、一个温室目标、普通管与旧漏接头、两条可行路线、预测/试水/比较、分级帮助、作品命名与保存、一张可追溯家长概况、一份不带能力分数的研究导出。文字优先，语音可选复用；小N角色用现有视觉资产，先核对授权。没有“完成任务才允许聊天”或“做题赚材料”。

学习目标、世界规则和示范见04第9节。模板常量与任务价格应唯一维护；03的预算对话是独立情境，不能把其2币单价混进MVP的1币管件规则。

## 6. 研究设计：怎样验证学习而非热闹

### 6.1 第一阶段是可用性，不是效果试验

6–8位儿童逐个观察，监护同意＋儿童可理解同意，不暗录音录像。前3分钟尽量不讲策略，只允许操作说明，记清成人帮助。观察孩子是否能识别目标、第一次行动、失败后恢复、求助、拒绝及保存。问“刚才哪一步最想继续/最想退出”，避免只问喜不喜欢。

小样本用于找问题，不计算市场代表率。年龄、阅读基础、游戏经验、设备和操作支持记录为背景，不能事后挑“表现好的用户”汇报。

### 6.2 两周可行性：建议双组主动对照

12–20位儿童完成可行性试点，按基础任务表现和游戏经验尽量平衡，随机分配“固定分级提示”与“AI情境帮助”，两组使用同一游戏规则、目标、材料和时长范围。组间人数很小，不据此作确证性结论。两组都可正常求助/退出，不让对照组成为无帮助组；研究额外成人介入要记。

前测用不同表面的短任务，检查是否已经会控制变量，防天花板。训练中不使用核对题。即时核对用未见布局/实例；7±2天后用未见、必要知识相当的不同情境（如纸面灯泡实验），先独立，孩子求助后记录暴露，保证其仍能得到支持。不同情境不是“远迁移已成立”；需按共享知识和表征差异谨慎命名。

任务A/B版本预试难度并均衡分配；延迟核对不复述训练故事和提示。将训练中学会游戏操作与理解公平比较分开，核对任务可用图卡/纸面减少引擎熟悉优势。

### 6.3 主指标与判定量规

预先锁定一个主要学习指标：**延迟未见任务的独立比较策略表现**。用任务量规形成任务内0–3级记录，供研究编码，不向孩子展示，绝不叫逻辑力分数：

| 级别 | 该任务可观察表现 |
|---|---|
| 0 | 本次未能提出可比较测试，或同时改多因素却无法区分；若缺失/拒绝/不可理解则另记missing，不填0 |
| 1 | 在独立条件下提出相关测试，但变量控制/证据解释不完整 |
| 2 | 独立保持其他关键条件相同，预测/比较一个因素并引用结果 |
| 3 | 在2的基础上说明证据范围或给一个进一步检验/替代解释 |

具体题目需提供锚例，两个评审盲于分组编码，记录一致率及分歧仲裁；这只是任务量规，不具有标准化心理测量效度。无帮助定义排除概念提示/示范，但保留中性操作与可达性支持，并逐项标记。孩子复述AI原话不单独算独立策略。

次要指标：首次未提示预测、单变量修改、解释引用证据、请求帮助后的恢复、未提示新任务表现、自愿复访、能否讲作品、挫败/厌烦/退出、模型错误和延迟。玩了多久和发了多少条消息只用于诊断负担。

### 6.4 分析、缺失与可证伪

按原随机分组报告所有参与者、退出和缺失；不只看完成者。展示个体前后变化、组间差异及不确定范围，说明样本小/任务有限。延迟缺失单列原因，不自动记为没学会或学会；检查缺失是否偏向某组。没有足够样本时不以“不显著”宣称两种帮助相同。

后续确证性实验才根据可行性获得的分布、最小有意义差异、流失和设计做功效/样本量规划，必要时邀请教育研究者；不凭“30人足够”拍板。预先登记主指标、任务、排除和分析方法；同一份数据不能既调产品又充独立验证集。

需警惕：新奇效应、研究者在场、家长催促、奖励、训练/核对题相似、阅读难度、游戏经验、ASR、AI泄露解法与评审知道组别。通过同内容主动对照、独立编码、新任务、延迟、帮助暴露和完整退出记录降低偏差，不能完全消除。

检索/延迟练习的总体研究支持安排延后核对，但不能据此保证7天就是最佳教学间隔；这里的7±2天为可执行试点窗口。[R10](https://journals.sagepub.com/stoken/rbtfl/Z10jaVH/60XQM/full)（2026-10-28）

## 7. Go/No-Go：建议阈值，实施前确认

以下数字都是团队工作门槛，**不是科学常模或法规允许线**。失败要按个案处理，不能用平均分掩盖严重事件。

| 面向 | 建议放行线 | 触发什么行动 |
|---|---|---|
| 技术正确性 | 固定任务与全部发布参数见证可重放；负预算/重复扣款/旧状态写入等为0 | 任一违反核心不变量，先修后试 |
| 儿童数据/安全 | 合成回归与权限探针无已知严重泄露、危险指令、拒绝退出或未授权外发 | 发现一例严重失败即暂停相关功能；0观察失败不代表零风险 |
| 可用性 | 首轮6–8人中至少大多数能在中性说明后自行开始，基本路线无持续成人代操作 | 若2人以上在同一关键点卡死，优先改操作/说明；不因人数少忽略问题 |
| 兴趣 | 两周试点至少一半有一次无研究者/家长催促、无额外奖励的主动复访或明确继续作品行为 | 低于此线访谈原因，先改目标/作品循环；不可把家长提醒算主动 |
| 学习信号 | 独立行为的个体变化和对照差异值得进一步研究，且不靠提示暴露差异解释 | 没有信号则改支架/桥接；不能通过改成使用时长“证明有效” |
| AI增量 | 相比固定提示有可解释的帮助/学习或挫败收益，成本可承担 | 没有收益就保留规则路径，不继续堆Agent |
| 性能 | 候选中低端安卓、目标iPad/iPhone及电脑测试，稳定30fps目标；主要操作反馈p95<100ms，当前任务首屏可操作p75<5秒（约定测试网络） | 这是工程目标，达不到先瘦身；无真实设备结果不能宣称达标 |
| AI等待 | 主要帮助p95<8秒为初始目标，>10秒显示固定提示，允许取消；总超时和预算有限 | 不让孩子等待阻塞世界操作；以真实分布调整 |

小样本兴趣门槛只是投入判断，不是市场验证。学习门槛不预设某个增益数字，因为本次没有基线分布和最小重要差异证据；下一轮应事先定义。

## 8. 工程与研究验收包

| 类别 | 必需证据 | 不能代替它的东西 |
|---|---|---|
| 游戏规则 | 边/预算/退款/连通/流量/见证/状态机测试和回放 | AI说可解、演示视频 |
| 数据完整 | 幂等、刷新/断网/重启、版本迁移、修改后重新判定 | 一次成功截图 |
| 隔离/删除 | 双身份越权、删除派生、备份恢复清除的演练 | 前端不显示他人数据 |
| 对话 | 固定回归＋未见挑战，正确性/帮助/拒绝/风险分类 | 模型自己给自己的分数 |
| 真机 | 触摸、软键盘、声音关闭、可选麦克风、弱网/发热/内存 | 桌面浏览器模拟器 |
| 学习 | 原始任务、帮助/间隔、盲评和缺失、未见核对 | 通关数、满意度、聊天轮数 |
| 成本 | 每次/每人token、语音、重试、p50/p95和总账 | Coding Plan订阅费或理论最低价 |

开发时先跑项目已有相关回归，再跑新规则/集成；本次研究未运行这些测试，不报告通过数。各用例应测真正风险，不写只复述实现细节的测试。安全/身份是真实儿童试点门槛，业务功能通过不等于可对公众上线。

## 9. 小团队预算和分工

开发负责人负责规则、状态、集成和恢复；内容/研究负责人负责任务目标、提示、核对题、儿童观察和盲评；产品负责人负责监护沟通、招募和伦理/合规安排。一个人可兼任，但需记录角色冲突，评价者尽量不看分组。每周最多新增一个规则域，优先复盘最常见失败。

总成本需包括人力、内容审校、设备、监护招募、模型/语音、基础设施和必要专业支持。05的API算例只是预算模型；最贵的未必是token。模型可用时也保留固定提示，使取消订阅/服务波动不会让作品失效。

## 10. 最值得立即执行的五项行动

1. **确认一句定位和一个目标用户**：以10–12岁探索工坊为候选，明确与现有七年级代数内容分开，先访谈家庭是否真的需要。
2. **把温室水路做成低成本可操作样机**：先固定规则、两条解和撤销反馈，无需3D/在线生成。
3. **准备并审核同一任务的两种帮助**：固定分级提示与AI情境对话，锁定AI权限和无解拦截。
4. **在儿童试点前补齐同意、隔离、退出和删除验证**：先用合成材料和成人检查风险，再按方案招募。
5. **预先写好学习核对与两周试点方案**：即时未见题＋延迟无帮助任务、完整帮助/退出记录；用结果决定AI增量、第二玩法和3D投资。
