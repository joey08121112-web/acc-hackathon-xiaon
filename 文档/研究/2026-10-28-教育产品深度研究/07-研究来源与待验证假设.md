# 学伴小N：研究来源与待验证假设

版本：研究建议 v1.0｜资料核验日：2026-10-28（北京时间）｜用途：产品决策、开发交接、试点设计。

## 1. 本次研究的方法和边界

本研究先检索官方产品/帮助资料、原始研究、研究综合与监管原文，再形成设计建议。它是有目的的桌面研究，不是注册过的系统综述，也不是实际儿童用户研究。检索覆盖 AI 导师、创作平台、互动模拟、自适应练习、游戏学习、支架、探究、动机、迁移和儿童保护。主要检索词包括 Khanmigo tutoring/safety/latest learnings、Minecraft build/assessment/Code Builder、guided inquiry meta-analysis、AI tutor randomized trial、far transfer、儿童个人信息及拟人化互动服务。

**未登录或购买任何竞品，未亲自体验其付费导师或儿童账号功能。** 文中的操作流程是官方资料重建；优缺点和可借鉴点是本研究的分析。没有开展儿童访谈、课堂实验、价格询价或付费 API 基准测试。没有修改现有产品代码、部署、提交或上传项目资料。没有使用真实学生数据。

证据标签：

| 标签 | 含义 | 能支持什么 | 不能支持什么 |
|---|---|---|---|
| F | 官方功能/帮助文档 | 产品公开提供或宣称的机制 | 功能可靠率、儿童实际体验、学习因果收益 |
| R1 | 元分析/研究综合 | 一类教学设计的总体方向及异质性 | 直接预测小N、某年龄、某玩法的效果 |
| R2 | 原始实验/观察研究 | 指定样本、条件、指标的结果 | 直接推广至所有儿童或长期发展 |
| T | 理论/经典原始论述 | 设计解释框架 | 单独证明产品有效 |
| L | 法规/权威政策指导 | 适用条件下的要求/建议 | 自动完成法律适用判断或上线许可 |
| C | 当前本地源码静态观察 | 看到某模块和逻辑存在 | 运行正确、生产已部署、真机/真实学生有效 |
| J/H | 研究判断/待检验假设 | 决策理由与实验方向 | 既成事实或科学定论 |

“较强/中等/较弱”是本报告对**具体推论**的定性评级，不冒称 GRADE 评级。官方营销不是独立效果证据；理论支持与因果验证分开。
