## 2. 综合模式（首页自由聊天）实现现状

**结论：不是普通聊天。** 已有一套「程序主控的阶段机 + 逐字证据观察 + 防护栏」：

- **阶段机**（纯函数，非模型判意图）：`listen→(probe|companion)→think→reflect`，外加安全词/休息词/告别优先拦截；每阶段允许模型输出的字段白名单，越权字段程序丢弃并写审计（`server/agents/stages.ts:40-76,24`；`server/agents/learning.ts:317-318`）。
- **意图来源三层**：客户端显式卡片枚举（`study|life|decline_study|start_together|formal_test`）+ 程序正则 + 学生显式点击；不靠模型自由判断（`shared/learning-contracts.ts:84`；`stages.ts:10-14`）。
- **生活场景观察**：11 个预置场景（故宫/球赛/零花钱等），触发词开局、逐问推进、每场限一次；观察必须逐字引用学生原话才入库（`server/plugins/life-scenes/index.ts:9-54`；`server/plugins/conversation/index.ts:14-21`）。
- **记忆系统**：草稿需学生确认；40 字上限、情绪/评价词正则拒绝、保留期（forever/7d/30d）；注入上下文经最长公共子串相关度筛选且 ≤5 条 ≤300 字；撤销经 25ms 权限指纹轮询即时生效并清除历史回执（`server/plugins/memory-flow/index.ts:27-39,104-123`；`server/agents/roles.ts:191-192`）。
- **防泄漏**：回复与未作答题参考答案做 NFKC 归一化子串比对，命中即拒（`server/agents/roles.ts:134-144`）；回复超 80 字先让模型改写再程序截断（`shared/learning-contracts.ts:150`）。
- **对话产物闭环**：错题记录（两次独立模型解题+程序核对答案才 verified）、进步卡（防「完全靠自己」虚假归因）、对话小结（跨场次同维度对比）、开场问候接上次小结（`server/plugins/problems/index.ts:58-83`；`progress/index.ts:14-19`；`conversation/index.ts:60-65`）。
- **语音**：双引擎 ASR（服务端/浏览器回退）+ VAD 端点检测 + 按句 TTS 边播边预取 + 连续对话循环（`src/voice/mic.ts:25-28`；`voice.ts:76-102`；`conversation.ts:6-44`）。

**教学策略层面**：提示词有教学取向（先倾听、不评判不说教、不逼问、引导式 probe），但属于「护栏型」——没有研究 03 提出的意图八分类与 ANSWER/CLARIFY/PROBE/HINT 九动作协议，好奇心激发不系统化。→ 差距见 02 §G1。

## 3. 专业模式实现现状

**结论：已实现的是「结构化测评 + 学习闭环」，不是游戏环境。**

- 五站式测评（理解花园→逻辑小桥→…→建模），题目只来自 `life-*` 生活故事题库（18 题已故事化，另有 10 题答案保密备用，见 `文档/交接/2026-10-24-专业模式题库28题与用法.md`）；等级由程序按 `LEVEL_BY_BASIS` 判定，模型只写措辞（`server/plugins/interview/index.ts:22-44`；`shared/learning-contracts.ts:165-167`）。
- 报告门控：等级与依据必须一致、引用必须存在、确认只能来自学生点击（`server/agents/professional.ts:15-74`）。
- 月阶段/周计划/复测提醒/月度趋势，全部程序派生（`server/plugins/tracking/index.ts:9-20`）。
- **前端形态**：SVG 静态地图 + DOM 选择题/文本题 + 语音作答。全 `src/` 无渲染循环、无实体系统、无瓦片地图；依赖里无 three/phaser/pixi/konva/matter（grep 与 lock 文件双确认）。唯一 canvas 用于拍照裁剪（`src/Upload.tsx:43-147`）。
- 首页→专业模式是「建议卡」不自动切换（`stages.ts:47`）。

即：**当前专业模式恰是任务书说「不希望」的答题闯关形态**；游戏化目标（探索/建造/互动即学习）实现度为零，但外围资产（吉祥物 SVG 及其情绪/触摸体系、语音管线、agent-client 请求层、契约体系）可复用。→ 见 02 §G3。

## 4. Agent / 工具 / 提示词架构

- **单一协调器** `LearningCoordinator`（`server/agents/learning.ts`），按需调用 5 种角色（tutor/assessor/planner/reporter/generator），角色间不自主协商——与研究 05 推荐的「程序主控、模型负责语言」**天然一致**。
- **11 个工具**，参数 schema 冻结在共享契约；角色白名单（tutor 9 个 / assessor 3 / planner 6 / generator 0）；每角色最多 4 轮、全场 6 次工具执行（`server/tools/registry.ts:7-14,41-105`）。
- 工具语义里的「程序优先」设计：`get_hint` 仅当学生自己请求过该级提示才放行；`record_stuck_point` 的 `studentQuote` 必须逐字出现在本轮学生消息里；`request_hint` 模型侧显式拒绝注册（防职责重复）；`grade_attempt` 只走注册的 rubric 引擎（`registry.ts:36,69-72,88,100-104`）。
- 输出防幻觉：严格 JSON + 一次修复轮；字段白名单 + 逐字段重过 zod；出题（E1）模型候选必须映射到白名单模板并由程序重算答案（`server/plugins/generation/validator.ts:55-70`）。
- 待清理：`reporter` 角色有策略与提示但无路由使用（`registry.ts:11`）——死代码候选。

## 5. 数据与记忆结构

- 每身份独立 SQLite（`users/<id>.sqlite`），身份库只存 token 哈希，伪造 cookie 不建库；运行时池空闲 30 分钟逐出（`server/storage/users.ts:18-31,58-62`）。
- 实体集合以 `entitySchemas` 为准（约 35 个：tasks/attempts/evidence/memories/episodes/observations/interviews/monthStages 等），追加式 + 幂等回执表 `operations`，同 key 异内容抛冲突，事务 `BEGIN IMMEDIATE`（`repository.ts:8-18,64-92`）。
- 跨会话聚合形态：对话小结（含跨次对比）、成长快照（等级标签+本月目标）、技能五状态、月度趋势——**没有自由文本画像**。
- 学习事实喂给模型的位置：tutor invoke 的 `data.context` 字段（`learning.ts:193,308`），程序硬上限。

## 6. 安全 / 隐私 / 性能

**安全**：
- 防线：Origin 白名单 + CSRF（timingSafeEqual）+ Host 校验 + 会话 cookie + `sec-fetch-site` 检查（`server/http/server.ts:50-77,190`）；安全词门在 chat/interview 最顶部拦截且**该轮不落库**（`learning.ts:154-155,387-389`）。
- 应用层限流：ASR 20/分/用户、TTS 30/分/用户、身份创建 30/分 + 总量上限、请求体分路由限制（`server.ts:97-99,117-119`；`users.ts:27-29`）。
- **缺口**：①`SAFETY_REPLY` 心理热线是占位 TODO（`learning.ts:46-47`）——真实儿童场景必须先补；②无按 IP 的全局限流中间件；③无模型输出侧内容安全审核层（结构门控不能替代语义审核）。

**隐私**：
- Key 只在服务端；日志仅 4 处且不落音频/识别文本；模型轨迹只存参数哈希（`registry.ts:110-111`）。
- `.env.server` 含真实 GLM/豆包 Key，位于工作目录但**从未进入 Git 历史**（本轮 `git log --all` 验证为空）且 `.gitignore:7-9` 覆盖 `.env.*`。注意打包/截图外传风险。
- 儿童数据全在本地 SQLite，`/api/learning/reset` 一键清空；试用时限 30 分钟/身份 + MAX_USERS=50 已上线（`7f83d55`）。
- **口径问题**：`chatLog` 逐字保存对话原文且无保留期限（reset 才清）——研究 05 §9 建议「文字聊天默认短期（如 7 天）」。→ ADR-005 待决策。

**性能**：
- 串行链路为主（工具循环、门控→单次模型调用均串行）；延迟拆账此前实测：说完→回复 6–9s = 隧道热身 0.5s + 上传 + ASR 约 1s + GLM 3–4s 地板 + 串行 reload + TTS 整段返回（`文档/审查/2026-10-24-语音链路检查与时延实测.md`）。
- TTS 对浏览器非流式（等完整 mp3）；对冲重发会**双路计费**（`hedge.ts`，研究 05 §11 特别提醒核对计费口径）。
- 仓储 `list()` 全表扫描无分页——单用户小数据量下可接受，是已知扩展点。
