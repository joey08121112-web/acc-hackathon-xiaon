## 4. ⭐ 本机网络：不用再关翻墙代理了（这次真正的收获）

**老问题**：FlClash 开 TUN 时，发到服务器 IP 的 TCP 会被吃掉——sshd 收不到 banner，
报 `Connection closed by 47.76.72.179 port 22`。以前的解法是「关掉 FlClash 换直连」，
**代价是用户整机断网**，用户 2026-11-21 明确抱怨过这一点。

**现在的解法（实测有效，且代理全程开着）**：

```sh
ssh -B en0 xiaon-prod '...'
```

或在 `~/.ssh/config` 的 `Host xiaon-prod` 块里加一行（**已加**）：

```
BindInterface en0
```

**原理**：把这台服务器的 socket 绑到物理网卡，路由查找就在 en0 上做，**绕开 TUN**；
其他流量照旧走代理。`route -n get default` 可查当前物理网卡名（本机是 `en0`）。

**踩过的坑（都试过，不通）**：
- `ssh -o ProxyCommand='nc -X 5 -x 127.0.0.1:7890 %h %p'`（SOCKS5）→ 同样被断
- `ssh -p 2222`（sshd 的备用端口）→ 同样被断
- **只加 /32 主机路由不够**：`route -n get` 显示已走 en0，SSH 仍断 → **必须绑接口**
- `route-exclude-address` 塞进 FlClash 的 `patchClashConfig.tun` → **不会被转发**到生成的 config.yaml；
  app 还会在重启时把自己的内存配置写回 `defaults`，覆盖掉手改的值
- 直接改 `~/Library/Application Support/com.follow.clash/config.yaml` → 生效了，
  但**订阅更新会重新生成该文件，手改必失效**（持久修法应写进 FlClash 的覆写脚本）

**因此给下一条的建议**：换网络导致网卡名不再是 `en0` 时，`~/.ssh/config` 里那行要跟着改。
