## 1. 项目是什么、代码在哪

- 产品：学伴小N（七年级数学学习支持手机网页应用，React + TypeScript + Vite 前端 + Node 后端）
- GitHub 仓库：https://github.com/joey08121112-web/acc-hackathon-xiaon（main 分支）
- **应用目录是仓库内的 `outputs/xiaon/`，不是仓库根目录**（所有构建/部署命令都在这个目录下执行）
- 架构：单 Node 进程同时托管前端静态文件 `dist/` 和 `/api/*` 后端；后端持有智谱 GLM Key 代理调用模型；SQLite 存学习记录（容器内 `/data/learning.sqlite`）。前端只请求同源 `/api`，页面与 API 必须同域名，不需要 Nginx
- Docker：`outputs/xiaon/Dockerfile`（node:22-bookworm-slim，npm ci → build → 单进程，监听 8080）

## 4. 环境变量

模型相关（已配在服务器 `/root/xiaon.env`，Key 明文只在那里和本机 `.env.server`）：

```
XIAON_GLM_API_KEY      = <智谱 GLM Coding Plan Key>
XIAON_GLM_MODEL        = glm-5.3-flash
XIAON_GLM_BASE_URL     = https://open.bigmodel.cn/api/coding/paas/v4
XIAON_GLM_TIMEOUT_MS   = 120000
XIAON_GLM_MAX_TOKENS   = 8192
```

**关键**：这个 Key 是个人 GLM Coding Plan 套餐的，必须用 `/api/coding/paas/v4` 基址；标准 API 基址 `/api/paas/v4` 会拒它（401）。另有豆包 TTS 四变量（`XIAON_TTS_PROVIDER` 等）已配好，语音朗读可用。

部署开关（`XIAON_PUBLIC_ORIGIN` 在 `docker create -e` 单独传，其余写死在 Dockerfile）：

```
XIAON_PUBLIC_ORIGIN = https://<当前隧道地址>   # 必须与实际访问域名一字不差、无末尾斜杠；地址变了必须重建容器
XIAON_API_HOST=0.0.0.0  XIAON_STATIC_DIR=dist  XIAON_DB_PATH=/data/learning.sqlite
```

## 5. 线上更新标准流程（已验证可用，停机 ≈ 10 秒）

本地（在仓库 `outputs/xiaon` 目录）：

```sh
cd outputs/xiaon
rm -f ../xiaon-cloudbase-deploy.zip
zip -rq ../xiaon-cloudbase-deploy.zip . -x "node_modules/*" -x ".local/*" -x "dist/*" -x ".env.server"
scp ../xiaon-cloudbase-deploy.zip root@8.210.88.178:/root/xiaon.zip
```

服务器（构建约 3 分钟，期间旧容器照跑不停机）：

```sh
rm -rf /opt/xiaon && unzip -q /root/xiaon.zip -d /opt/xiaon
cd /opt/xiaon && docker build -t xiaon:latest .
docker stop xiaon
docker cp xiaon:/data /root/xiaon-data-restore        # 容器无卷，学习记录必须先备份
docker rm xiaon
docker create --name xiaon --restart unless-stopped \
  -p 127.0.0.1:8080:8080 \
  --env-file /root/xiaon.env \
  -e XIAON_PUBLIC_ORIGIN="$(sh /root/tunnel-url.sh)" \
  xiaon:latest
docker start xiaon && sleep 4 && docker stop xiaon    # 让 bootstrap 建好 /data
docker cp /root/xiaon-data-restore/. xiaon:/data/     # 恢复学习记录
docker start xiaon
curl 127.0.0.1:8080/api/health                        # 应返回 "mode":"model"
```

隧道是独立 systemd 服务，更新容器不影响它，URL 不变。

## 6. 隧道重启会换地址（重要）

quick tunnel 每次重启地址都变。地址变了就：服务器 `sh /root/tunnel-url.sh` 拿新地址 → `docker rm -f xiaon` → 按第 5 节 `docker create`（PUBLIC_ORIGIN 用新地址）→ start → 外网 curl health 验证 → 同步更新提交表/海报里的链接。

## 7. 已知约束（别踩坑）

- **单用户产品**：SQLite 整库 = 一个学生。两人同时用会互相看到记录、模型请求 409 排队。演示一个一个来；评委体验前在「我的与设置」点「重置整个演示」。
- **服务器时钟是 UTC**（比北京慢 8 小时），看 `docker images` 的 "N minutes ago" 别误判。
- **探索地域对境外入站有过滤**：国内访问 80/443 正常，但 Let's Encrypt 验证节点超时、证书签不出——别试图改 sslip.io + Caddy 直连方案，只能走 Cloudflare 隧道（Caddy 装过但已 stop/disable 留存）。
- **HTTPS 硬要求**（前端用 `crypto.randomUUID()`），裸 IP http 打不开。
- `glm.ts` 的 `thinking:{type:'disabled'}` 是有意为之（提速），别改回。
- Coding Plan Key 限流按单人设计，评委短期体验没问题，别长期对外开放。
- Zeabur 已关停勿用。从零部署备选：Railway（主）/ 腾讯云 CloudBase（国内）/ Render（兜底）/ 本机 `./demo-tunnel.sh`，完整步骤见仓库 `outputs/xiaon/DEPLOY.md`。
