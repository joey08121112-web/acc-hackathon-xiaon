## 3. 怎么体验（三种方式，优先方式一）

### 方式一：线上地址（推荐，手机/电脑均可，无需安装）

**https://committees-fibre-trend-forever.trycloudflare.com**

- 10-22 00:20 实测 health：`mode=model`（真实 GLM）、`tts:true`（豆包朗读已配）、`asr:false`（语音输入未配）。**不需要任何 Key**，第 4 节 A–G 全部可测。
- 这是比赛提交的演示链接，手机浏览器直接打开即可（微信内打开若异常，换系统浏览器）。
- **四条必读注意：**
  1. **单用户共享库**：线上只有一份数据库，多人同时操作会互相看到记录。请**轮流体验**（群里喊一声“我开始了/我结束了”），每人结束时在“我的与设置”里**重置整个演示**再交给下一位。
  2. **限额共享**：E1 出题每日 12 次、每场次 5 道，是全站共用的，别刻意耗尽，留给其他队友。
  3. **地址可能变化**：这是 Cloudflare 临时隧道，服务器重启后 URL 会换。打不开先在群里确认最新地址，不要当缺陷报。
  4. 不要输入真实学生姓名、学校、联系方式等真实信息（聊天文字会发给模型）。

### 方式二：本地全功能运行（可选，适合要跑脚本自检或想独立数据的技术队友）

GitHub main 已同步到最新（`204597f`）：

```sh
git clone https://github.com/joey08121112-web/acc-hackathon-xiaon.git
cd acc-hackathon-xiaon/outputs/xiaon
npm ci      # Node ≥ 22.13
XIAON_UI_PORT=5195 XIAON_API_PORT=18935 XIAON_DB_PATH=.local/teammate-你的名字.sqlite npm run dev:learning
```

打开 http://127.0.0.1:5195/（按你实际端口）。每人用独立端口和 `XIAON_DB_PATH`。真实模型/出题需 `.env.server` 填 `XIAON_GLM_API_KEY`（找我要，参照 `.env.example`）；没 Key 时应用明确降级为本地规则模式——评分、证据、报告、计划、复习仍可跑，这本身也是一个检查点。语音需另填豆包四变量，没有则本地语音项 ⏭。

### 方式三：离线体验包（无网备用）

解压 `outputs/学伴小N-队友体验包.zip`，双击 `双击打开-学伴小N.html` 用 Chrome/Edge 打开。**局限：10-21 上午的离线规则版**，只能测第 4 节 A、C（部分）、H（部分）；首页改版、E1 出题、语音、专业模式一律测不到。
