# 现在如何看

点开 [打开与分享页面](http://localhost:5173/share.html)，然后点“现在打开可交互原型”。也可直接打开 [小N原型](http://localhost:5173/)。请不要再打开源码里的 index.html。

你当前若停在必要信息页：“未满14周岁”需要先点击“发起监护人确认演示”→“模拟监护人阅读并确认”，才可继续。队友用虚构资料体验时，可选择“成年体验者”，再确认必要信息、关闭可选功能进入。

# 发给队友

发送文件“学伴小N-队友体验包.zip”，不要把 localhost 地址当成异地链接。源码 ZIP 留给需要继续开发的同学。

队友操作：保存ZIP到电脑→解压→用Chrome或Edge打开“双击打开-学伴小N.html”。无需Node.js。不要在微信、网盘或压缩软件中直接预览。手机直接点链接体验需要另行提供在线网址，本次没有发布到公网。

体验路线和反馈提示详见包内“先看这里-使用说明.txt”。另有“发给队友的话术.txt”，可以整段复制发送。

# 已验证与限制

当前本地服务正常，打开与分享页面可运行。新增单文件版在HTTP环境中已经验证主要交互、无外部脚本/样式加载及ZIP下载。工具策略不允许file://，直接双击模式未实测；手机文件预览、队友实际设备也未验收。
