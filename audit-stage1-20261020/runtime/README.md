# 学伴小N · 慢慢来，也会到达

一版完整连贯的手机网页交互原型，面向七年级数学学习。原创二维小N、探索地图、合成对话和原创题目；不连接真实模型或学生数据。

## 不安装开发环境：发给队友体验

先打开 **http://localhost:5173/share.html**，可进入原型、下载队友体验包和查看使用方法。

直接双击本项目根目录的 `index.html` 会失败，因为它是开发源码入口。试用同学请接收交付目录里的 **学伴小N-队友体验包.zip**，解压后用电脑 Chrome/Edge 打开 `双击打开-学伴小N.html`；不要用微信、网盘或压缩软件的文件预览。

队友包不需要 Node.js，使用说明和开源组件许可随包提供。自包含 HTML 已在 HTTP 浏览器环境验证主要交互，没有外部脚本或样式请求；当前工具禁止 file://，直接双击模式未实际验证。手机文件预览不保证运行脚本；异地手机点链接体验需要另行提供在线网址，本次没有发布到公网。

开发同学可执行 `npm run build:offline`，将在项目相邻的 `team/` 中生成自包含 HTML；压缩该目录可形成体验包。现成交付包已配齐使用说明。

## 打开与运行

当前本地服务：**http://localhost:5173/**。

在项目目录运行（建议 Node.js 22.12 或更高版本，本次使用 26.8.2）：

```sh
npm ci
npm run dev
```

Vite 默认使用 5173 端口，监听本机网络接口。仅用于本机/可信局域网体验，没有发布到公网。如果端口已占用，可使用 `npm run dev -- --port 5174`。

```sh
npm run build       # TypeScript 检查和生产构建
npm run preview     # 预览生产构建，默认 4173 端口
npm test            # 17 项纯业务规则测试
npx playwright install chromium  # 首次运行浏览器测试前安装测试浏览器
npm run test:browser # 17 条核心流程及无障碍检查 + 1 条单文件分享测试
```

`package-lock.json` 已锁定实际安装版本。正式静态文件输出到 `dist/`，应通过 HTTP 服务打开，不能直接双击 `dist/index.html`。

截图画廊：服务启动后打开 **http://localhost:5173/review.html**。画廊是交付审阅附件，不属于学生产品导航。

## 建议体验路线

1. 首次介绍 → 必要信息。默认未满 14 周岁，需要走一次明确标记的监护确认演示，可体验待确认、失败、取消、演示完成。
2. 在可选功能页选择“关闭可选功能，进入基本体验”。长期记忆、研究用途均不影响基本学习。
3. 主页“先聊聊”，输入“这次考砸了，有点难过”。对话来自本地规则，一次只问一个主要问题。
4. 自主选择“一起看一道题”。点击填入错误示例 `x − 5`，提交 → 一级提示 → 修改成 `x + 5`。
5. 暂停、刷新、继续，草稿和提示仍在。查看报告中的“提示下完成”及可展开的作答证据。
6. 选择同类新题，首次不使用提示回答 `4a + 2`。观察报告改变，并在阶段回顾中区分原题、提示完成和新题独立完成。
7. 接受、减量、改期或暂不开始周计划，前往今日页核对安排。
8. 探索地图/列表先进行理解与逻辑，再进入计算、建模、空间想象。空间任务可普通点击选择，正确项为 B。
9. 头像 → 设置，体验记忆开关、更正/删除、断网演示、帮助支持、监护人页面。
10. 看题弹窗选择“我想先带来一道题”，使用本地示例，完成真实裁剪、手动遮挡与内容核对。

验收辅助入口均在“我的与设置”：大字体、断网与失败演示、重新体验首次进入、重置整个演示。重新首次介绍保留学习进度；重置会清空本原型的本机进度、图片和长期记忆。断网演示开关仅在当前页面有效，刷新后关闭。

## 设计说明

- **自己的节奏**：首页把“聊聊、看题、休息”放在同一层选择中，先听意愿；休息后隐藏学习邀请，今日页停止任务安排。恢复由学生主动选择。
- **安静的识别度**：奶油纸色、鼠尾草绿、少量暖黄；原创小芽形象采用 SVG 渐变、柔和轮廓与轻微呼吸动画。没有系统 emoji 品牌头像，也没有图片或字体外部请求。
- **探索与专注分开**：地图像一本小小的旅行手记；进入任务后收起地图与大型形象，保留题目、作答、提示和暂停。
- **进步有来处**：不使用能力百分制、雷达图或连续打卡排名。观察优先呈现已有依据的维度，未观察项明确保留；固定方法笔记来自已完成任务，不重复发放。
- **手机优先**：390px 为主要设计视口；响应式支持 320–430px 手机宽度，桌面增加安静的品牌侧栏。触控目标、16px 表单输入、安全区域、动态视口和减少动效均已处理。

## 已实现的前端交互

首次介绍与授权、可恢复聊天、看题与步骤记录、提示、失败重试、暂停恢复、图片选择/裁剪/遮挡/编辑、五维地图和列表、五类完整任务、基于作答的观察、证据展开、文本导出、周计划/今日/阶段回顾、记忆管理、隐私说明、求助及不安全联系人分流、监护确认和查阅申请状态。

题目化简使用确定性的一次式解析与最终结果核对，不执行输入文字。可以提交结果或以 `=` 连接的等式步骤；不是任意数学证明或自然语言解题理解。错误等式不能靠最后写一个正确答案蒙混过关。

计算题数量按**本次已打开的不同计算题**计数，最多 10 题，包含原题、同类新题和错误后邀请的补充题。失败重试、修改与刷新不会增加同一题的计数，计算达到上限后仍可回看已打开题目。暂停和未完成不计入“弱”。

## 进度与长期记忆的区别

| 本机项目 | 用途 | 关闭长期记忆后的行为 |
| --- | --- | --- |
| `xiaon-progress-v1` | 当前聊天、作答、草稿、提示、计划、授权和流程状态，便于刷新恢复 | 仍保存，支持基本体验 |
| `xiaon-memory-v1` | 主动保留的偏好、完成表现、学习观察及来源时间 | 不再新增或使用；已有条目可更正、删除 |
| `xiaon-image-v1` / `xiaon-image-work-v1` | 已选/处理图片、裁剪遮挡步骤、核对草稿 | 与学习进度一样独立处理 |

记忆关闭后，已经在等待的提交也不会再追加长期条目。删除长期记忆不篡改原始作答；清除原始进度可使用“重置整个演示”。应用没有实现本机内容的应用层加密，因此只适合合成材料。

## 合理假设与本次边界

- 只有七年级示例课程；教材选择用于展示用户偏好，不宣称已经覆盖整套教材。
- 地图先安排理解、逻辑；这两项有过尝试即可进入其他站点，不要求答对。聊天里的“一起看题”是学生自主选择的独立入口，仍进入同一份学习记录。
- 提示使用在每次提交时留存快照。首次不使用提示且结果正确才计入本题独立完成；反复修改原题不增加独立题量。
- 学习观察从有限的当前记录推导。例如错误结果与漏改符号一致时，会明确保留“具体步骤仍需核对”，不直接推断学生的心理过程。
- 错误新题提供同环节的补充题邀请，属于本地规则式的轻量适应；不是经过测量学验证的自适应测评系统。
- 原创题目和参考解答已经核对，但有限题量不足以证明完整能力、长期掌握或分数提升。
- 本机保存与可选长期记忆分开；关闭长期记忆不等于删除所有用于当前演示的聊天和任务数据，界面中已说明。
- 默认没有外部通知。求助联系人是虚构方向，没有真实姓名、号码、通讯录或通知权限。

## 明确属于模拟的能力

| 项目 | 当前行为 |
| --- | --- |
| AI 聊天 | 本地规则及预设文本，带等待、失败、暂停、重试状态；未接入模型 |
| 题目识别 | 固定原创示例结果，显著标注未接入 OCR，可手动修改；不会对任意图片假装识别成功 |
| 图片上传 | 实际为前端本机选择和处理，无网络上传；遮挡结果写进图片像素 |
| 监护确认/身份核验 | 独立的确认演示，不是勾选即真实核验，也没有真正访问隔离 |
| 研究用途 | 独立授权状态演示，没有研究收集或传输 |
| 联系人通知 | 全部本地状态；“已发送”不代表已读或帮助到达，失败有替代路径 |
| 查阅申请与反馈 | 范围、核验、处理和结果演示，没有受理后台或人工值守 |

## 未来需接入的真实服务

1. 模型服务、可靠的数学步骤核验、适龄内容治理、人工复核与质量评估；需要独立验证安全支持流程，不能依赖少量关键词或页面提示。
2. OCR、图片脱敏复核与受控上传存储；识别置信度、失败处理和用户核对。
3. 真实身份/监护关系核验、服务端权限控制；敏感倾诉的访问边界必须由后台实现。
4. 授权撤回、研究用途治理、访问日志、明确的数据保存删除策略、信息权利与反馈受理。
5. 经确认的可信联系人、真实通知与送达状态；安全联系人筛选与地区适用的正规求助资源。不能把模拟发送当成有人已提供帮助。
6. 内容审查、用户研究、真实设备验收和正式合规工作。当前原型没有宣称满足所有上线要求。

## 代码结构

`src/domain.ts` 管理状态、恢复、题量限制、作答证据和观察；`data.ts` 包含原创题目及确定性核对；`Upload.tsx` 负责图片流程；`Art.tsx` 是原创形象与图形；`App.tsx` 串联页面；`style.css` 提供完整视觉系统。浏览器测试在 `tests/`，业务规则测试在 `src/domain.test.ts`。
