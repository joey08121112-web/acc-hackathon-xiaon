## 3. 问题列表

### S1-01 · P2 · 窄屏地图的重要状态字号过小，大字体设置不生效于这些文字

**事实，已复现。**320px宽度下，地点名称计算字号10.5px，“暂未完成”“完成”“未开始”“从这里开始”等状态字号7.95px；开启“大字体”后这些数值不变，而页面正文已经放大。

- **实际影响：**需要较大字体的学生仍难读清地点状态及开始提示。不是纯装饰文字，影响判断该去哪里、哪里尚未完成。列表模式可绕行，因此不定为P1。
- **对应需求：**阶段1的“地图有清楚状态”“手机阅读、大字体”；原始提示词“正文易读、状态不只依赖颜色、大字体不溢出”。
- **前置条件：**完成首次介绍，在我的与设置中开启大字体。已有作答不是必要条件；本轮另保留理解暂停、计算提示后完成的状态。
- **复现：**将浏览器设置为320×740 → 探索 → 地图入口 → 查看地点名和状态；关闭大字体后重复比较。
- **预期：**地点名和关键状态应随阅读设置变大，地图空间不足时重排或明确采用可读列表，不靠缩小状态字容纳。
- **实际：**大字体开/关均为10.5px和7.95px；没有同步放大。
- **证据：**[大字体地图](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/16-map-320-large.png)、[正常字号地图](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/23-map-320-normal.png)、[大字体测量](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/map-large-metrics.json)、[正常测量](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/map-normal-metrics.json)、[可绕行的列表](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/17-list-320-large.png)。
- **位置：**[style.css:2740](/Users/ami/Documents/个人/ACC黑客松/outputs/xiaon/src/style.css:2740)和[大字体规则:2448](/Users/ami/Documents/个人/ACC黑客松/outputs/xiaon/src/style.css:2448)。小屏规则使用rem；大字体只改变局部容器字号，没有覆盖地图标签。
- **最小方向：**给地图地点名和状态明确的大字体样式，并重新安排节点或切换可读布局。建议将普通状态至少提升至12–14px、较大字号再同步放大，具体值经手机试用确认。这是修复建议，不是引用某个法定最小字号，也不据此宣称WCAG违规。

### S1-02 · P2 · 选择“现在先不看”后，聊天仍突出展示相同的看题邀请

**事实，已复现。**聊天中打开看题确认，选择“现在先不看”，只关闭弹窗；“如果愿意，我们可以只看一道题 / 我愿意”邀请和“我愿意试试”快捷项仍在。自然语言表达不想看题后，也没有对应的“只聊聊”呈现状态。

- **实际影响：**学生已经拒绝当前邀请，却仍看到相同引导，界面没有表达其选择已被接受。可忽略邀请继续输入，或使用“今天先休息”，因此为P2。后一绕行会把学生带回休息主页，不等于明确选择“继续聊天但不做题”。
- **对应需求：**阶段1的自主选择、探索确认与退出设计；原始提示词“先倾听、再邀请行动”“模式切换需要学生明确选择”；本轮共同边界要求检查模拟演示自洽。拒绝后停止催促是用户阶段2检查条目，本轮仅记录已经可见的设计状态缺口，不扩展成阶段2全套验收。
- **前置条件：**已进入基本体验，未选择休息。
- **复现：**小N → 先聊聊 → 邀请条“我愿意” → 确认弹窗“现在先不看” → 查看回到聊天后的邀请条及快捷项。可额外发送“现在不想看题，只想聊聊”观察文案。
- **预期：**明确接收“暂不看题”，当前聊天优先继续倾听；主动学习入口可保留，但不继续突出相同邀请。重新邀请应由学生再次选择或合适的明确时机触发。
- **实际：**弹窗关闭后恢复原邀请展示；没有“暂不看题”的界面状态。**没有观察到自动进入题目、强制学习或新增自动弹窗**，不能将其写成自动跳转、情绪操纵或真实模型拒绝失效。
- **证据：**[拒绝前弹窗](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/20-decline-dialog.png)、[拒绝后聊天](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/21-after-decline.png)及同名txt；[自然语言拒绝的聊天](/Users/ami/Documents/个人/ACC黑客松/audit-stage1-20261020/evidence/05-chat-refusal.png)。
- **位置：**[App.tsx:915](/Users/ami/Documents/个人/ACC黑客松/outputs/xiaon/src/App.tsx:915)仅以休息状态控制邀请；[App.tsx:2755](/Users/ami/Documents/个人/ACC黑客松/outputs/xiaon/src/App.tsx:2755)的拒绝按钮只关闭弹窗。
- **最小方向：**增加“当前对话暂不邀请看题”的状态及简短确认表达，抑制当前邀请与同义快捷项，保留学生主动重新开始的入口。无需为此接入真实模型或改写整套聊天。
