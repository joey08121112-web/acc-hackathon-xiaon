# 学伴小N · 本机受控学习Agent

2026-10-21 D集成版。保留原手机网页与离线规则体验，接入本机Node/SQLite、B评分证据、C差异化计划和复习；Tutor、Assessor、PlannerReporter有独立prompt、输入、权限、输出校验与轨迹。

## 启动

在本目录（Node ≥22.13，当前实测26.8.2）运行：

```sh
npm ci
npm run dev:learning
```

打开 **http://127.0.0.1:5194/**。前端5194、API18931都仅监听loopback；Ctrl+C只关闭本命令创建的进程。若端口被占用，不关闭别人的进程，可用 `XIAON_API_PORT=18935 XIAON_UI_PORT=5195 npm run dev:learning`。

数据库默认 `.local/learning.sqlite`；可用 `XIAON_DB_PATH=.local/my-synthetic-trial.sqlite npm run dev:learning` 选择新的合成体验数据库。不同origin拥有各自的浏览器缓存；SQLite由同一个API服务提供，不要把多个测试窗口连到自己的日常数据库。

两终端方式：

```sh
XIAON_API_PORT=18931 XIAON_ALLOWED_ORIGINS=http://127.0.0.1:5194 npm run server
XIAON_API_TARGET=http://127.0.0.1:18931 npm run dev -- --host 127.0.0.1 --port 5194 --strictPort
```

## 模型与数据用途

`.env.server` 只在服务端读取，沿用 `.env.example` 的 XIAON_GLM_API_KEY / XIAON_GLM_MODEL / XIAON_GLM_BASE_URL / TIMEOUT_MS / MAX_TOKENS。默认 glm-5.3-flash；按A阶段用户确认保留个人Coding Plan基址；不把Key写到VITE变量、聊天或前端。未配置Key时明确显示本地规则，程序评分、证据、报告、计划和复习仍可运行，需要开放解释分析的部分保留待核查。synthetic只在显式测试夹具中启用。

真实模型发送范围：Tutor当前一条消息、必要学习上下文及许可偏好；Assessor可信题面/rubric、原始作答及暴露快照；PlannerReporter程序生成的报告事实和计划草案。角色不互传全部聊天。外部已发送内容无法追溯撤回。只使用合成学习材料。不是公网部署方案、没有账号或真实监护核验，数据库没有应用层加密。

[官方Coding Plan接入与套餐适用范围](https://docs.bigmodel.cn/cn/coding-plan/quick-start)限定指定工具/产品环境；当前配置与本次开发验收不能作为正式教学产品可使用该套餐的保证，产品化时需确认适用套餐，或配置对应标准API与Key。不要仅改基址混用不同类型Key。

## 从选择到复习

1. 完成首次介绍，可关闭全部可选功能。首页“先聊聊”使用Tutor；明确休息/不看题由程序优先处理，即使模型等待中也能暂停。
2. 首页“一起看一道题”→“我愿意，从示例题开始”。若缺先修，先确认“合并同类项”，尝试 `5x-4`。再由探索页选择“去括号负号处理”。五维探索新场次先尝试理解与逻辑；支持入口与探索共用题库和记录。需要解释的题第一行写结果，第二行写理由；离线时不把正确选项当完整理解。
3. 负号题尝试 `x-5` → 看一级提示 → 修改 `x+5`。每次提交先保存原始尝试与暴露快照；提示完成与首次独立完成分开，刷新保留草稿，失败可用原请求重试。
4. “查看作答证据”→生成报告与计划草案。报告只渲染受控事实/推断/未知和原始引用，模型不能自行添加分数。历史报告、计划均可选择查看。
5. 计划页接受、减量、改期或暂不开始；今日页显示学生确认目标、当日安排和真实到期队列。到期后由学生确认一道未见新题或明确选择原题回顾；题库不足明说，不自动开题。
6. 正常跨日期的新学习会开始新场次；同日刷新/暂停/模式切换不重置10道计算题预算。稳定状态依B产品规则要求多道未见题、多日期与多场次，不能把同日刷题当跨次稳定。
7. 记忆页的新增、更正、停用、删除及开关真实影响后续上下文。作答/计划属于必要记录，关闭偏好不抹去它们。

跨天测试使用独立TestClock，不改电脑时间；正式服务没有改时间路由。正常体验请等待真实到期，不要以测试脚本更改日常库。

## 受控出题（E1，2026-10-21）

只开放 **去括号负号处理（negative-brackets）** 与 **合并同类项（like-terms）** 两个知识点；其他四维、文字解释、图形、证明和应用题仍只用原题库。

入口：作答过一道这两类题后的题目页、成长页对应知识点卡片的“针对这个环节出一道新题”、今日页到期复习（题库不足时直接显示，题库还有时折叠在“或者根据这个环节出一道新题”）。题库里还有未做过的同类题时先提供原题。

流程：学生点击 → 程序门控（暂停、先修、探索顺序、本场次 10 道计算题、本场次出题上限、当日次数、时间预算、复习是否到期、是否配置模型）→ 只把该知识点最近 ≤6 次作答的判定、分类、提示依赖、错误线索和证据 ID 发给 Generator（不发学生原文和聊天；可选记忆关闭时不发偏好）→ 模型只选择白名单模板和整数参数，并写出题面/答案/步骤供核对 → 程序按模板**自己**计算题面、答案、提示和典型错误，逐项比对模型写的内容，并用现有判题器确认可判、按内容指纹去重 → 通过后写入不可变 TaskDefinition 和 GenerationRecord。每次操作最多 2 次模型回应（1 次候选 + 1 次修复），不调用工具。

发布 ≠ 已看过：新题只显示“针对的环节、依据、难度、预计用时”，学生确认后才展示题面并记录暴露。之后与原题库完全同路：提示、判题、证据、报告、计划、到期复习、跨场次检验。生成题是同族换数变式，做对不代表更广泛迁移。

失败与回退：取消、超时、暂停、重置都会丢弃迟到结果；两次都没通过校验时显示原因、不发布任何题；未配置模型时明确提示并保留原题库。

限额（非密钥，可选环境变量）：`XIAON_GENERATION_TIMEOUT_MS`（默认 60000）、`XIAON_GENERATION_DAILY_LIMIT`（默认 12 次/上海日期）、`XIAON_GENERATION_SESSION_LIMIT`（默认 5 道/场次）、`XIAON_GENERATION_MAX_ROUNDS`（1 或 2）。模型、Key 与基址沿用 `XIAON_GLM_*`。

验证：`npm run test:agent:e`（模板独立算术、校验器、全链路、HTTP）、`npm run test:agent:e:browser`（独立 5197/18938、临时库、模拟模型、TestClock 推进到生成题复习）、`npm run test:agent:e:real`（真实 GLM，合成材料、临时库；无 Key 时退出 2 并标记未运行）。规则详见 `文档/交接/2026-10-21/交付/E/GENERATION-RULES.md`。

## 数据迁移与恢复

新版学习事实以SQLite为准；`xiaon-workspace-v2`只是草稿、导航、显示聊天和待重试请求的恢复缓存；`xiaon-sqlite-active`避免服务断开后静默落回旧学习事实。原 `xiaon-progress-v1`、记忆、图片不自动清空，也不与新证据双写。

记忆页→“导入旧浏览器作答”→下载备份与预览→确认只导入原始尝试。重复导入去重，任一无效旧题回滚整次导入；不信任旧correct布尔值，不导入聊天/图片/旧计划/偏好。旧时间、场次和暴露未知保持未知，不能补成跨天完成。

取消/网络失败后草稿与待重试请求保留，重试复用operationId。模型分析失败的已保存尝试可“重试分析已保存作答”；重新评分追加修订，原记录和历史报告保留。服务重启后本机会话会重建，幂等收据仍在SQLite。

“我的与设置→重置整个演示→确认清空本机演示”同时清除新版SQLite、草稿与旧浏览器记录/图片。服务断开时停止清除，不显示虚假成功；不承诺取证级磁盘擦除或撤回已发出的外部请求。

## 离线与既有分享资料

`npm run dev`仍可单独启动原规则版；服务未接入时明确降级。已切换SQLite的浏览器断开服务时显示等待，不把旧作答重新当新版状态。

离线候选必须单独输出，避免覆盖现有队友材料：

```sh
npm run build
node scripts/build-offline.mjs /absolute/path/to/new-candidate-directory
```

生成的单文件版显式为“离线规则版·无后台Agent”；无服务端、SQLite、模型凭据或额外资源请求。本次候选在D/evidence/offline-candidate，不替换既有分享ZIP或public/offline.html。HTTP环境中的自包含运行已测；直接file://、真实手机及软键盘未测。

限制：为了保留原离线规则，同一前端包仍保留旧固定题与受限答案核对，不能称为防查看源码的考试系统；新版B完整rubric与答案库没有打入前端。当前是本机单用户合成材料版本，不含OCR、真实通知、真实身份/监护核验、云同步、任意出题（E1只在两个知识点的白名单模板内受控出题）或通用自主Agent。真实设备、真实学生、长期教学效果和整版第三方独立验收未运行。
