## 测试先行矩阵

所有画像和题库使用明确标注的合成数据。时间由冻结 Clock 注入，持久化用临时 SQLite；不访问用户浏览器、修改电脑时间或实际等待数天。

| 场景 | 应验证的行为 |
| --- | --- |
| 完整排程 | 完成时刻起默认 1 天到期；到期独立正确后分别从本次真实完成时刻安排 3、7、14 天；阶段耗尽后的语义按冻结协议明确，不无限生成 |
| 到期边界 | 到期前 1 毫秒、正好到期、之后查询；查询本身不升级、不新增尝试、不重复生成任务 |
| 当天重复 | 同日改答、原题重做、伪造新场次均不能速通阶段；可信跨场次与最低间隔同时成立才允许进级 |
| 结果分流 | 独立正确、帮助后正确、错误、needs_review 对应不同安排及原因；待核查不作为确定错误、不推进稳定状态 |
| 缺席 | 推进 Clock 而没有完成事件，只形成到期状态，不降低能力、不自动进级 |
| 跨次累计 | 区分当天修改、原题重做、延迟未见新题独立完成；保留每次来源场次/题目版本/证据 ID |
| 具体困难 | 去括号提示依赖与建模关系困难得到不同知识点、候选题、依据与替代选项 |
| 无记录 | 仅提供可选探索，明确未知，不出现负号薄弱或其他个性化断言 |
| 稳定表现 | 已有可信延迟跨次独立记录时安排延迟检查，避免重复入门辅导 |
| 优先级 | 到期且需支持、提示依赖/近期错误、证据不足、表现良好待延迟检查按规则排序 |
| 暴露 | 题面已见、提示、聊天答案暴露均进入资格判断；暴露过的题不得作为未见新题独立检验 |
| 题库不足 | 返回 exhausted 和原因；可回顾原题但明确标注，不编造题目或把原题包装为新题 |
| 先修/预算 | 建议保留理解/逻辑先行、先修关系、学生选择、题量与时间预算以及计算每场次最多 10 题约束 |
| 可信场次 | 重启/刷新不重置同一场次计数；新 session ID 本身不证明可绕过场次限制；主控仍负责最终门控 |
| 延期 | 原到期时间、新时间、原因和 revision 保留；旧任务失效；重复 operationId 不重复创建 |
| 休息与恢复 | 暂停队列仍可查看但不催促/自动开题；恢复不集中堆积补做任务；无负面能力证据 |
| 学生四分支 | 接受、减量、改期、暂不开始均源于真实学生事件；草案不覆盖当前已确认计划 |
| 过期确认 | 旧 revision 确认提示重新核对；不得覆盖新计划；重复确认幂等、操作冲突明确 |
| 重启恢复 | 关闭临时库并重新打开，队列、确认事件、报告与计划历史不丢失、不重复生成 |
| 上海午夜 | 2026-10-20T15:59:59.999Z 与 16:00:00.000Z 分别显示上海 10 月 20 日及 21 日；不用宿主默认时区 |
| 旧时间 | 缺年份/时区的旧 timeLabel 保留未知，不猜 UTC、不伪造到期与跨次稳定 |
| 历史不可变 | 新证据创建新报告/草案；旧快照内容保持；打开/刷新不刷重复版本 |
| 评分更正 | 追加修订后可重算当前安排；旧报告保留原文并标注依据已修订，提供新版；已否定观察不得继续作为当前事实 |
| 记忆关闭 | 不新增/检索可选长期偏好；必要学习记录和学生确认计划仍按 A 权限工作 |

## 四种合成画像的预期方向

| 合成输入语义 | 预期主要目标 | 事实限制 |
| --- | --- | --- |
| 去括号曾错误，提示后正确，无延迟独立新题 | 针对去括号环节帮助，随后未见同类题复查 | 不从答案直接推断心理过程，不称稳定掌握 |
| 建模关系证据显示需要支持 | 识别数量关系与一次性费用，先修不足时给替代探索 | 不套用负号辅导；不复制 B 评分逻辑 |
| 多场次、满足间隔、未见新题独立完成 | 延迟迁移检查 | 不称长期教学效果已证实 |
| 完全无记录 | 自选理解/逻辑探索 | 无个性化能力结论，无虚构依据 ID |

每项计划应可追溯知识点、任务类型、预计时间、日期、依据 ID、目标和状态；默认一个主要目标。报告应区分事实、推断、未知，保留证据 revision、覆盖、变化与后续建议。
