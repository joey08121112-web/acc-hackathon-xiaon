# 评分、证据与状态规则

## 确定性与辅助评分边界

可信题库仅在服务端。客观选项由程序精确核对；一次式通过既有data.ts/correct()支持的有限语法核对，不复制解析器、不eval。用每步与自身比较探测可解析性，再将完整等号链的每一步与可信目标比较。计算题另起行的式子也纳入等价链，不能在第一行写对后藏入矛盾步骤。

支持x/a、数字、加减、括号、常数乘一次式、显式`*`或`×`；支持`4*a+2`、`4×a+2`、`+4a+2`等。不是任意方程/证明/自然语言求解器。一次式最多2000字符、最多32个左括号；超范围、非线性、未知符号、空等号步骤和无作答为uncertain/needs_review，不强行算错。旧选择题v1按其原始答案文字复核，不伪造现代rubric解释。

所需解释逐评分点由注入的分析器处理。模型只收必要题面/选项/空间数据、可信rubric、已保存value及帮助快照，无完整聊天历史、可选画像或记忆。严格JSON、评分点集合完整且无重复/未知字段；quote必须等于本次value的UTF-16半开区间。解释引用必须在结果第一行之后。位置校验只能证明引用来自此作答，不能替代语义正确性；本轮语义输出均为合成模型，没有真实模型准确率结论。

程序与模型的结果点评分冲突返回needs_review；程序证据保留。没有模型、无有效解释、引用不属于本次作答、错误偏移/空引用、输出畸形、失败、超时、意外tool call等也待核查。结果正确但理由缺失不能升为全部rubric通过。模型不能改原始Attempt、可信答案或自由写长期画像。实际供应商协议由A provider负责，本批没有新增适配器。

错误结果恰好与commonErrors.indicator相同时只产生待核实线索；不由最终答案推断学生“忘了”“不懂”或其他心理过程。

## 独立、帮助、重做

1. 忽略纯空白尝试作为能力证据；未开始、暂停、缺席和未评分不记弱。
2. 使用作答保存时的exposureIds、hintSnapshot、answerExposed，而非当前题目的可变提示状态。hint/answer/chat_help在提交之前存在则为帮助。提交后同版本提示不会追溯改变过去独立记录。
3. 查同原题ID（跨版本保守关联）及相同题面此前所有有效原始尝试；首次错误后修改正确永不冒充首次独立。评分修订不删除原始错误。
4. 此前场次已打开、或同一场次在更早上海日期已打开的原题，不算未见题迁移；可标原题重做。此前有可信不同日期尝试，且本次不借帮助完成时，另记delayedRetention。单独延迟保持不增加新题独立数量/可信独立日期。
5. 旧版本评分仅保留结果事实，历史timeLabel不补年份、时区或场次。legacy_unknown、无可信场次、缺暴露快照等不升级独立证据。
6. A快照仅收同版本暴露；B对同原题跨版本、严格较早的可信暴露补做保守核对。跨版本题面事件与提交时间相同则novelty=unknown：冻结协议无全局序号，不能猜先后。此时保留原始作答/正确结果，但不凭它证明未见题独立；额外的同毫秒跨版本资料可能增加未知项。D如需消除此不确定性，应统一补足可信顺序或规范化别名快照，不能从旧时间标签补造。
7. 新题首次有效尝试、无关键帮助且完整可信历史、全部评分点正确，才记new_independent。简单换数虽可算不同题，覆盖仍只限同题族，不等于广泛迁移。

kind与novelty分别保留：比如原题曾见、提示后才正确，可以同时为`completed_with_help`和`seen`。不强行用单一标签抹去其他事实。

## 五档状态与修订

| 冻结枚举 | 展示 | 规则 |
| --- | --- | --- |
| unobserved | 尚未观察 | 没有可支持下列状态的证据；已有未知/原题重做事实仍在coverage、attemptIds和unknowns，不等于“没有记录” |
| needs_support | 需要支持 | 有确定未通过或原题修改完成，但尚无独立/提示完成依据；不作人格评价 |
| completed_with_help | 提示后完成 | 有正确且已获帮助的记录 |
| first_independent | 首次独立完成 | 至少1道未见题首次有效尝试正确，无帮助 |
| cross_session_independent | 跨次独立完成 | 默认至少2道不同未见题、2个可信Asia/Shanghai学习日期、2个场次满足独立条件 |

阈值各允许2–30的整数配置，默认2/2/2，只是产品规则，不是标准化测评。相同日期大量题不升为跨次；同一天结束重开场次仍不满足两日期。每个子技能独立计算，计算的负号去括号与合并同类项不互相代替。

采用每次尝试最新有效GradingResult；regrade用supersedesGradingId/supersedesEvidenceId追加。旧记录、旧快照永不覆盖。snapshot使用当前evidenceRevision，生成后再次请求同operationId仍取旧快照；新operationId才重算。所有事实可从仓库尝试、暴露、评分和证据重算。

后续确定失败不删除此前成功；recentDifficulty单独提示最近有效结果仍有困难。待核查和未评分进入unknowns，不强制解释为能力弱。五维只输出覆盖、有效评分点数量、最近可信时间及缺项，无平均分、智力、人格或天赋推断。

冻结ID数组上限为500；当前合成验证远低于此限。长期大量记录超过快照容量需要D统一设计分页/证据摘要；没有验证无限数据规模，也没有删除原始记录来迎合上限。
