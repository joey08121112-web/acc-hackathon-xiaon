# 学伴小N首页改版：三路并行总控

编制日期：2026-10-21。这是实施任务书，不是已完成的功能。三路分别交给 Claude、ChatGPT、zCode 三个开发工具执行。

## 一、要做成什么

按产品海报《心事有人听，进步有人记》改版。完整方案见 claude.ai 上的「学伴小N 改版方案」文档（由用户分享）；本目录的任务书已把每一路需要的方案细节写全，执行者不需要额外读那份文档。

| 改造 | 内容 | 对应海报 |
| --- | --- | --- |
| 一 | 首页综合模式（**第一优先**）：小N先开口，平复情绪，轻松地聊考试；聊天中留意理解和逻辑；结束时给对话小结和计划建议；学生确认后可切到专业模式（现有五维探索） | 01、02 |
| 二 | 说出卡点：拍照 / 口述 / 从题库挑，三选一，都存成同一种「错题记录」 | — |
| 三 | 一起思考（逐级引导，完成前不给答案）+ 进步卡 | 03 |
| 四 | 按错题出题并进入复习；模型出的题必须过多轮审核 | — |
| 五 | 记得你说过的小事：对话里提议记住，下次见面主动提起 | 04 |
| 六 | 专业模式（**第二优先**，底部导航第二个「探索」改名）：面试式依次测理解 → 逻辑 → 计算 → 建模 → 空间想象，出评测报告、学习建议，周任务为主、月任务为阶段的规划，长期跟踪 | — |

**已拍板的决定（执行时不得自行改变）**

1. 进步卡三栏：今天的小突破 / 这次有用的方法 / 下次想试试，另加可跳过的信心自评（更有把握 / 差不多 / 仍不确定 / 暂不回答）。AI 写草稿，学生确认后才保存。AI 同时从小突破和好方法里提炼一句记忆草稿，一起给学生确认。
2. 记忆开关由学生自己选：首次介绍时明确问一次，不替学生默认勾选。关闭时不提议、不提起，但在首页和进步卡处显示「记忆已关，小N不会记住这次的方法，下次也不会主动提起」，并给去打开的入口。
3. 陪聊边界：学生连续只聊生活一段时间后，小N轻轻问一句要不要看看学习；学生拒绝，本次场次内不再问。何时问由程序按轮次判定，不由模型决定。
4. 识题模型沿用 `glm-5.3-flash`（团队确认支持视觉），开发前用一张合成错题图做冒烟测试并留档。
5. 照片隐私：上传前必经遮挡步骤（可选「没有需要遮挡的」）；只发裁剪后的部分；服务端只转发一次，不存图、不记日志；发送前写清发给谁、发什么。
6. 模型生成的题可以进复习，但必须先通过多轮审核（见第三期任务）；答案只在服务端。
7. 学生完成前坚持引导、不给答案，帮助逐级给并记录为暴露事件；完成后学生想看解析可以看。
8. 离线单文件版不改，保留旧首页作为无网备用。
9. 「专业模式」就是现有五维探索。只在对话里建议，学生点确认才切换。
10. 综合模式聊天里只对理解、逻辑两维记「对话观察」：每条附学生原话、标「待核实」，不改五维评分。要确认就建议去专业模式。不问「你读懂了吗」，而是问题目里具体条件的意思，看学生理解得对不对；情绪没平复时不试探，试探有频率上限。
11. 对学生的评价存为学习记录（「对话小结」），不受记忆开关影响，学生在成长页可见；情绪不记成标签；下次对话拿来对比。
12. 首次介绍里告知一句：「聊天时小N会留意你怎么读题、怎么想，帮你找方法，不打分。」
13. 对话结束（学生点「今天先聊到这」或道别）时生成小结：聊了什么、对话观察、和上次比、1–3 个计划建议（可转成正式计划）、专业模式建议（情绪未平复时不提）。
14. 专业模式的题目：现有题库题打底，小N用聊天口吻出题，并追问「你是怎么想的」；答错时加问一道同类题，分清是一时失误还是真的卡住。不让模型现场出测评题。
15. 专业模式的顺序：理解、逻辑必测且先测，之后按计算 → 建模 → 空间想象接着测；可随时暂停，下次从停下的模块接着测；测完理解和逻辑就能出报告，没测的标「还没测到」。
16. 评测报告：每个模块给等级（掌握得不错 / 部分掌握 / 需要加强 / 还没测到），由程序按作答证据判定，模型只负责措辞；附依据原话和学习建议；不给总分、不排名，标明「本次观察」。报告里对照综合模式的「待核实」观察是否得到确认。
17. 学习规划：每月一个阶段目标，拆成每周的小任务（沿用现有计划的确认、减量、改期、暂不开始）；月底建议做一次专业模式复测并与上月对比。只在 app 内提醒。
18. 测试中可以给一点小提示，如实记为「提示后完成」。报告、月阶段、对话小结都是学习记录，不受记忆开关影响；成长页新增「成长档案」，按月看五个模块的等级变化。
19. 题库扩充暂缓：本轮不扩题库，专业模式用现有 28 道题。复测时同类未见题不够，按现有规则明说「题库不足」，不能把见过的题当成未见题。题库编写模板已另行准备，团队之后再填。
20. 第三期 A 线（扩展出题模板）依赖题库扩充，本轮暂缓；Claude 第三期改做集成、回归和 PRD 同步草案。
21. 本轮仍是单用户演示库，不做登录和多人数据隔离；对外演示前先「重置整个演示」。数据要存得住：固定数据库路径、可备份可恢复（ChatGPT 第一期 C）。
22. 记忆按需取用：Tutor 上下文只取当前相关的 3–5 条有效记忆并限制总长度（zCode 实现，阶段 0 留接口）。Tutor 回复长度由程序校验，不只靠提示词。「学生确认」只能由程序根据学生的点击或输入写入，不能由模型传入的字段决定。

## 七、所有新功能都要遵守

- **安全拦截优先**：首页综合模式、一起思考、专业模式面试，所有学生输入都先过现有安全拦截（`SAFETY_PATTERN`）和休息、暂停处理，再进入任何阶段。命中时显示求助信息，不生成观察、小结或评分。
- **没有模型也能用**：每个新功能都要写清本地规则模式下的行为。综合模式用固定的温和回复，不产生观察；小结由程序拼装（只有聊了什么和计划建议）；专业模式照常用程序判分，追问用固定问法；问候用默认文字；识题改为手动输入。
- **重置演示**：「重置整个演示」要清除所有新增集合，服务断开时不假装清除成功。
- **学生看到的文字**：不出现 SQLite、Agent、证据版本、接口名等工程用语；这些只在开发者模式里显示。
- **手机优先**：所有新界面在 390 宽下可用，键盘弹起时输入框不被遮挡。
