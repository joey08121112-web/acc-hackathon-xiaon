# zCode 路测试用例清单（阶段 0 交付）

编制日期：2026-10-21。覆盖第一期 A（口述卡点与错题记录）、第一期 B（记忆与开场问候）、第二期（周/月规划与长期跟踪）、第三期（拍照识题）。实现按批补进 `tests-agent/i/`，每条先写测试、首次失败原样留档。共同前提：所有用例只用合成学习材料；涉及学生原话校验的一律用脚本自造句子。

## 第一期 A：口述卡点与错题记录（tests-agent/i/problem-*）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| A1 | 模型产出草稿但学生未点「记下」 | 不写入 `problems` 集合；确认卡消失后草稿作废 |
| A2 | 学生点「改一下」后编辑文字再确认 | 保存的是学生改后的文字，不是模型草稿原文 |
| A3 | 草稿 `knowledgePointId` 不在现有 6 个之内（如 "quadratic"） | 程序改为 `other`，不报错、不采纳模型自造知识点 |
| A4 | 模型编造的 `stuckPoint` / `questionText`（学生本场次说过的话里找不到出处） | 该字段被丢弃；出处匹配按学生原话子串（宽松空白/标点） |
| A5 | 草稿缺题目文字或卡点（不完整） | 不展示确认卡，不写库 |
| A6 | 两次独立解题结果不一致；或无法用 expression.ts 核对且两次文本不一致 | `answerStatus: 'unknown'`，不写 `ProblemSecret` |
| A7 | 参考答案保密 | `view()`、HTTP 响应、服务日志、runs/toolCalls 轨迹里全文检索不到答案字符串 |
| A8 | 模型离线（OfflineProvider）时口述错题 | 手动确认仍能保存错题记录；无参考答案字段泄露，标注 `unknown` |
| A9 | 「从题库挑」入口 | 进入现有探索页，不新增题 |
| A10 | 只有知识点、无题目文字 | 确认后给该知识点题库同类题建议（复用现有选题），由学生确认后进入一起思考 |
| A11 | ProblemList（成长页挂载位） | 按时间倒序列出已确认记录，显示来源/知识点/卡点；未确认的不出现 |
| A12 | 重置整个演示 | `problems`、`problemSecrets` 等新增集合一并清空 |

## 第一期 B：记忆与开场问候（tests-agent/i/memory-*）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| B1 | 记忆开关关闭时模型输出 memoryDraft | 一律丢弃；不提议、不落库 |
| B2 | 关闭状态首页/进步卡提示 | 显示「记忆已关…」文案，含去打开入口 |
| B3 | 学生未点「记住」/点「不用了」 | 不保存；点「记住」才写 `MemoryItem`（source: student_explicit, purpose: tutoring） |
| B4 | 「改一下」后确认 | 保存学生改后的文字 |
| B5 | 情绪类/评价类草稿（「他很焦虑」「数学差」） | 被 `validateMemoryDraft` 丢弃 |
| B6 | 草稿超过 40 字 | 丢弃 |
| B7 | 同一场次第 3 次提议 | `shouldOfferMemory` 返回 false，不再展示 |
| B8 | 进步卡来源草稿（origin: progress_card） | 走同一个 MemoryPrompt 界面与确认流程 |
| B9 | greeting：有上一份对话小结 | 优先引用 `latestSummary` 接话题，即使记忆关闭 |
| B10 | greeting：无小结、有有效记忆 | 程序挑选记忆（优先久未提起），模型只措辞；写入 `memoryMentions` |
| B11 | 同一条记忆 3 天内重复提起 | 用 TestClock 验证被抑制 |
| B12 | 删除/停用/过期（expiresAt）/到期待复核（reviewAt）的记忆 | 不进入问候与 Tutor 上下文 |
| B13 | 首次见面、关闭且无小结、模型失败 | 返回默认问候并标 `memoryOff`/降级原因 |
| B14 | 模型离线 | greeting 仍返回默认文字，不抛错 |
| B15 | selectMemoriesForContext | ≤5 条、总长 ≤300 字、去重、同一件事更正后只取最新 |
| B16 | Tutor 回复长度程序校验 | 超长回复被程序拦截/截断（不只靠提示词） |
| B17 | 「学生确认」写入 | 只能由程序根据学生点击/输入写入；模型传出 `studentConfirmed: true` 不生效（沿用 P0 检查） |
| B18 | 记忆时效选择「记 7 天 / 记 30 天」 | `expiresAt`/`reviewAt` 正确写入；满 30 天长期记忆在记忆页出现「这条还适用吗？」 |
| B19 | 重置演示 | 新增集合（memoryMentions、memoryDrafts 等）一并清除 |

## 第二期：周/月规划与长期跟踪（tests-agent/i/plan-*，等 revamp-base2 后实现）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| C1 | 月阶段目标模块选择 | 「需要加强」优先于「部分掌握」；「还没测到」不选；由程序按等级决定 |
| C2 | 学生不确认 | `MonthStage` 不生效 |
| C3 | 拆周任务 | 走现有计划模块公开接口，产生计划版本历史，不绕开确认/减量/改期 |
| C4 | 月底复测提醒 | 到期前 3 天起提示；学生拒绝后本月不再提（TestClock 推进） |
| C5 | 长期趋势 | 同月多次测评取最近一次；全部历史保留可查 |
| C6 | 记忆关闭不影响 | 规划/月阶段/趋势照常生成 |
| C7 | 重置演示 | stages/trends 集合清除 |

## 视觉模型冒烟（阶段 0，scripts/agent/vision-smoke.ts）

- 无 Key：退出码 2，输出「未运行」（已验证）。
